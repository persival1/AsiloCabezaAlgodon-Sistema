Diagrama de Componentes

Arquitectura del sistema: Clean Architecture en el backend (4 proyectos .NET) + SPA de React independiente, comunicados por HTTPS/JWT. Las flechas muestran la dirección real de las dependencias entre proyectos.

Notas de arquitectura

  • Regla de dependencia: las flechas siempre apuntan hacia adentro. Ninguna capa interna conoce a una externa — por eso Domain no importa nada de Infrastructure.
  • CQRS con MediatR: cada caso de uso (crear solicitud, registrar visita, despachar prescripción...) es un Command o Query con su propio Handler dentro de Application. El Controller solo hace _mediator.Send(comando).
  • Infrastructure implementa, no decide: interfaces como ISolicitudRepository o IEmailService viven en Application; Infrastructure las implementa con Entity Framework Core, BCrypt y SMTP.
  • El frontend nunca toca la base de datos directo — todo pasa por la API, autenticada con JWT en el header Authorization: Bearer.
